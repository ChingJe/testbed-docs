# Design

本目錄保存已確認且仍適用於新版 NWDAF testbed 的穩定設計，包括 topology、component
placement、network planes、configuration ownership、runtime lifecycle 與 observability
boundaries。

尚未核准的候選設計應留在 `plans/`；單次驗證結果應放在 `records/`。目前既有 foundation
文件仍以歷史整體計畫形式保存在 `records/flat-federated-learning/foundation/`，後續 testbed adaptation 確認後再從
實際 repository 與驗證證據整理新的 canonical design，不直接複製舊計畫內容。
