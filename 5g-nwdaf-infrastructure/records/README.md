# Records

本目錄保存新版 NWDAF testbed 已完成工作的歷史證據，並依執行時採用的架構世代分類。

| 分類 | 內容 |
| --- | --- |
| [flat-federated-learning/](flat-federated-learning/README.md) | flat FL testbed 的初始建置與 validation evidence |
| [hierarchical-federated-learning/](hierarchical-federated-learning/README.md) | explicit Flat／HFL component baselines 與後續 testbed evidence |

Record 必須連同日期、實際 revisions、environment、commands、results、skips 與已知限制解讀。
舊 record 不因目前 source 前進而自動失效或重新變成 active plan，但也不能用來宣稱新 revision
已通過相同驗證。

HFL runtime 執行紀錄應在實際 testbed adaptation 或 experiment run 產生 evidence 後才建立；source
baseline record 不得用來宣稱尚未執行的 Flat／HFL runtime scenario 已完成。
