## 1. 視覺調整：背景色、edge label、節點名稱

### 背景色

`index.html` 的 `body` CSS 改成 `background: #000`，同時把 topology.js 裡的節點底色從 `#1a1a2e` 改成 `#263238`，compound parent（NWDAF 框）改成 `#0d1a20`。

### Edge label：縮寫顯示 + hover 完整名稱

之前 canvas 上直接顯示完整介面名稱，字串太長又常被節點擋住。

現在的做法：
- `topology.yaml` 的 `edge_styles` 裡加一個選填的 `short` 欄位：
  ```yaml
  Nnwdaf_EventsSubscription_Subscribe:
    short: NnwdafSub
    color: "#ce93d8"
    ...
  ```
- canvas 上的邊顯示 `short`，同時在邊的資料裡存一份 `fullLabel`
- `index.html` 加了一個絕對定位的 `<div id="edge-tooltip">`，滑鼠移到邊上時用 JS 把 `fullLabel` 填進去並定位到游標旁邊

Cytoscape.js 的 label z-index 有 bug，常被節點蓋住，tooltip 用 `position: fixed` 繞過這個問題。

### AnLF↔MTLF 雙向邊弧線

AccuracyReport（AnLF→MTLF）和 ModelProvision（MTLF→AnLF）兩條邊方向相反、位置幾乎重疊，標籤會互蓋。

在 `event_reactions` 裡加 `classes: arc-above` / `classes: arc-above-rev`：
```yaml
accuracy:
  - flash_edge: { from: nwdaf_anlf, to: nwdaf_mtlf, label: AccuracyReport, classes: arc-above }
retrain_done:
  - flash_edge: { from: nwdaf_mtlf, to: nwdaf_anlf, label: ModelProvision, classes: arc-above-rev }
```

對應的 Cytoscape.js CSS：
```js
{ selector: 'edge.arc-above',
  style: { 'curve-style': 'unbundled-bezier', 'control-point-distances': [-60], ... } }
```

負的 `control-point-distances` 讓曲線往上拱，兩條線就分開了。

### 節點顯示名稱

`topology.yaml` 的 `nodes` 裡 `id` 和 `label` 分開：
```yaml
- id: upf_ees
  label: UPF-EES1
```
程式用 `id` 定位節點，`label` 只是畫面上顯示的字串。原本 id 和 label 綁在一起，改 label 要改程式碼。

## 2. Grafana 互動：可拖曳選時間範圍、曲線可開關

### 核心：從 public dashboard 換成 anonymous viewer

原本用 Grafana public dashboard API 建立一個 token，iframe src 指向 `/public-dashboards/{accessToken}`。Public dashboard 模式是唯讀的，完全不能互動。

改成 anonymous viewer + kiosk mode，iframe src 改為：
```
/d/{uid}?orgId=1&kiosk&theme=dark&refresh=5s&from=now-3m&to=now
```

`kiosk` 參數隱藏 Grafana 的頂部導覽列，讓畫面更乾淨。這個模式下 Grafana 是一個正常的已登入 session（anonymous 身份），所以可以互動。

### 設定：`setup.sh` 自動寫入 `[auth.anonymous]`

```ini
[auth.anonymous]
enabled = true
org_name = Main Org.
org_role = Viewer
```

### API 端點調整

原本是 `/api/grafana-token`，改成 `/api/grafana-config`，回傳：
```json
{ "base": "http://...:3000", "uid": "nwdaf-traffic" }
```

`events.js` fetch 這個 config，首次收到 `aggregated_slot` event 時才建立 iframe，避免空圖。

### ↺ Live 按鈕

縮放時間範圍後 Grafana 不再自動追蹤 live。Header 加了一個按鈕，點下去直接重設 iframe src 回 `from=now-Nm&to=now`，分鐘數可以在旁邊的 input 調。

### Retrain annotation：`idelta` vs `changes`

原本 Grafana annotation query：
```
changes(nwdaf_retrain_total[1m]) > 0
```
問題：`changes()` 需要在 1 分鐘的窗口裡有超過一個資料點才算。Prometheus scrape interval 是 5s，但 annotation step 是 60s，等於每分鐘才評估一次，retrain 標記會晚很久才出現。

改成：
```
idelta(nwdaf_retrain_total[15s]) > 0
```
`idelta` 取窗口內最後兩個樣本的差，只要最近 15s 內 counter 有增加就立刻觸發。搭配 `step: 5s`，retrain 事件幾乎即時出現在圖上。

## 3. Filter sidebar

### 資料結構

兩個 JS object 追蹤可見性：
```js
const _nodeFilter = {};  // { "nwdaf_anlf": true, "smf": false, ... }
const _edgeFilter = {};  // { "Nnwdaf_EventsSubscription_Subscribe": true, ... }
```

父子節點關係：
```js
const _nodeChildren = {};  // { "nwdaf": ["nwdaf_anlf", "nwdaf_mtlf"] }
```
隱藏 NWDAF 時，子節點的 checkbox 會變灰（`disabled`）並跟著隱藏，不用各自手動關。

### 套用 filter

`_applyFilter()` 直接操作 Cytoscape：
```js
cy.nodes().forEach(n => {
  if (_nodeFilter[n.id()] === false) n.hide(); else n.show();
});
cy.edges().forEach(e => {
  if (_edgeFilter[e.data('edgeType')] === false) e.hide(); else e.show();
});
```

每個邊在建立時存了 `edgeType`（label 的第一個 token，去掉動態的後綴，例如 `"ThresholdBreach 2/3"` → `"ThresholdBreach"`），filter 用這個 key 查。

## 4. Config-driven topology

### topology.yaml 結構

```
nodes       → 節點 ID、位置、label、parent（compound 關係）
nf_aliases  → parser 的 NF 名稱 → node ID（例如 "AnLF" → "nwdaf_anlf"）
edge_styles → label → 顏色、寬度、消失時間、縮寫
layout      → 初始 zoom 和 pan
panels      → topology/charts/eventlog 的初始大小
event_reactions → 每種 event 觸發的視覺動作清單
```

後端 `GET /api/topology-config` 直接把 YAML 解析成 JSON 丟給前端，不做額外處理（只加一個 `_profile` 欄位標記目前是哪個 profile）。

### event_reactions：YAML 定義 + JS 執行

以前 `events.js` 裡有一大串 if/else：
```js
if (t === 'sbi_call') { flashEdge(...); pulse(...); }
else if (t === 'retrain_trigger') { addClassToNode(...); ... }
```

現在這些都在 YAML 裡：
```yaml
retrain_trigger:
  - add_class: { node: nwdaf_mtlf, class: retraining }
  - flash_edge: { from: nwdaf_mtlf, to: nwdaf_mtlf, label: RetrainTrigger }
  - pulse: { node: nwdaf_mtlf, color: "#ff7043" }
```

JS 裡的 `_executeAction()` 負責把這些動作翻譯成實際的 Cytoscape 操作。

`{field}` 語法可以引用 event payload 的欄位，例如：
```yaml
sbi_call:
  - flash_edge: { from: "{from}", to: "{to}", label: "{label}" }
```
`sbi_call` event 的 payload 裡有 `from`、`to`、`label`，`_resolve()` 在執行時把 `{from}` 替換成實際值。

`_resolveNode()` 多加一步：先做 `{field}` 替換，再用 `NODE_ID`（也就是 `nf_aliases`）做一次名稱轉換，把 parser NF 名稱轉成 Cytoscape node ID。

### Metric handlers 模組化

之前 Prometheus Gauge/Counter 的定義和更新邏輯都在 `main.py`，和 WebSocket broadcast、Grafana setup 等邏輯混在一起。

現在的結構：
- `rules/nwdaf.py` 裡定義 metric 物件，加 `METRIC_HANDLERS` dict：
  ```python
  METRIC_HANDLERS = {
      "aggregated_slot": _on_aggregated_slot,
      "ml_inference": _on_ml_inference,
      ...
  }
  ```
- `rules/__init__.py` 用 `pkgutil.iter_modules` 自動掃描所有 rule module，把各自的 `METRIC_HANDLERS` 合併成 `ALL_METRIC_HANDLERS`
- `main.py` 只剩：
  ```python
  def _update_metrics(event):
      for handler in ALL_METRIC_HANDLERS.get(event.get("type"), []):
          handler(event)
  ```

好處：之後要加新的 metric，只需要在對應的 rule module 裡加函式和 `METRIC_HANDLERS` 條目，`main.py` 完全不用動。

### Profile 系統

`topology.yaml` 和 `.env` 從根目錄移到 `profiles/default/`。

`start.sh` 接受 `-p <profile>` flag，export `PROFILE` 環境變數給 Python 讀：
```bash
./start.sh -p lab2  # 用 profiles/lab2/ 下的設定
```

Python 側（`config.py` 和 `main.py`）讀 `os.environ.get("PROFILE", "default")` 來決定要載入哪個 profile 目錄的設定。

### 拖曳 resizer

三個區塊（topology-row、charts、eventlog）之間各有一條 5px 高的 resizer bar，可以拖曳調整大小。

實作上比較麻煩的地方：Grafana iframe 在 focus 狀態下會吃掉 `mousemove` 事件，導致拖曳卡住。解法是 mousedown 時在最上層蓋一個透明的全頁 div（`position:fixed; inset:0; z-index:9997`），讓所有滑鼠事件都落在這個 div 上，mouseup 後再移除。
