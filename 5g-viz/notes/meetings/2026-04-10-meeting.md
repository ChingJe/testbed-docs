# 2026/4/10

## Testbed 視覺化 - 上次開會老師提出的改善項目

### 背景顏色、邊 label 命名、節點顯示名稱

- topology 與 Grafana 背景色統一、對比度調高
- 邊 label 全部換成 3GPP 規格介面名稱，hover 顯示完整名稱
- `UPF-EES` 改為 `UPF-EES1`，與 `UPF-EES2` 對稱

### Grafana 可互動

- zoom in 特定時間區間、UL/DL 曲線可個別開關
    - 原本嵌入的 Grafana iframe 無法互動，現在可以直接在畫面上拖曳選取時間範圍放大
    - 可點 legend 個別開關 UL/DL ground truth / predicted 曲線
    - Header 加入 ↺ Live 按鈕，縮放後一鍵回到 live 視窗

### Node 和 Edge 的 filter

- 可只看特定 NF 或特定 SBI call 類型
    - 側欄 filter panel，per-node 與 per-edge-type checkbox 各自獨立
    - NWDAF 為 compound parent，隱藏時子節點（AnLF/MTLF）跟著隱藏

### Config-driven topology

- 節點、邊、事件行為可設定，不需改程式碼
    - 拓樸佈局、邊樣式、每種 event 對應的視覺動作都改由設定檔驅動
    - 加入 profile 系統，切換不同部署環境只需換一份設定
    - 拖曳 resizer 可即時調整各區塊大小
- 尚未覆蓋：
    - 要連哪台 VM、tail 哪個 log file 目前仍硬編碼在程式碼裡
    - 新增 VM 或 log 來源還需要改程式碼
